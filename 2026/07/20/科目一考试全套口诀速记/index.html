科目一考试全套口诀速记

记录科一备考期间的考点

一、车速限速题

口诀1：城市30、50；公路40、70

详细解释：区分道路有无中心线，是科目一车速题核心考点，无特殊路况默认此标准：

  • 无中心线窄路：城市道路最高30km/h，乡村公路最高40km/h

  • 有中心线宽路：城市道路最高50km/h，乡村公路最高70km/h

口诀2：特殊路况一律30

详细解释：所有视线受阻、路况复杂、操作受限场景，最高车速统一30km/h：雨天、雾天、冰雪、泥泞路面；车辆掉头、转弯、下坡行驶；窄路、窄桥、铁路道口；进出非机动车道、学校居民区路段。

口诀3：高速速距分层，能见度定速距

详细解释：高速公路车速、车距严格按车道、能见度划分，是高频判断题、选择题考点：

  • 车道限速：三车道（左110-120、中90-110、右60-90）；两车道（左100-120、右60-100），高速最低车速60km/h，最高120km/h

  • 能见度限速：能见度＜200米，车速≤60、车距≥100米；能见度＜100米，车速≤40、车距≥50米；能见度＜50米，车速≤20，立即驶离高速

二、安全距离与停车禁忌题

口诀1：站三口五

详细解释：固定禁停距离，考试无例外：

  • 站三：公交站、加油站、消防栓、急救站周边30米内禁止停车

  • 口五：十字路口、铁路道口、陡坡、隧道、急弯周边50米内禁止停车

口诀2：普50-100，高150

详细解释：车辆故障警示标志放置距离：普通道路故障，警示牌放置车后50-100米；高速公路故障，警示牌必须放置车后150米以外，人员立刻撤离护栏外。

口诀3：雨雪雾天，距加倍

详细解释：雨雪、大雾、结冰路面摩擦力下降，刹车距离变长，跟车、会车安全距离需为正常天气的2倍，禁止跟车过近、紧急刹车。

三、灯光使用规则

口诀1：动变超靠必打灯，夜间会车近光灯

详细解释：起步、转弯、变道、超车、靠边停车五大操作，必须提前开启转向灯；夜间两车交会、近距离跟车，全程使用近光灯，严禁远光炫目。

口诀2：雾天雾灯双闪，绝不远光

详细解释：大雾、暴雨等低能见度天气，远光灯会被雾气反射，造成视线盲区，仅可开启前雾灯、后雾灯、危险报警闪光灯（双闪）。

口诀3：隧道近光，无灯远光，超车交替

详细解释：进入隧道、地下车库必须开近光，禁止远光；夜间无路灯、无对向车辆可开远光；夜间超车、提醒前车，交替使用远近光灯示意。

四、通行让行优先级（必考判断）

口诀1：转让直，右让左，下坡让上坡

详细解释：核心路权规则，全网通用：

  • 转弯让直行：直行车辆路权最高，所有转弯车辆必须礼让直行车辆、行人先行。
  • 右转让左转：相对方向两车，一车左转、一车右转，右转车辆主动礼让左转车辆先行（左转行驶轨迹更长，容易卡在路口）。
  • 下坡让上坡：狭窄坡道，上坡车辆起步、倒车难度大，下坡车辆停车让上坡车先行。

口诀2：无障让有障，临崖让靠山

详细解释：单侧障碍物路段，无障碍一侧车辆减速礼让有障碍一侧；山路窄路，外侧临崖车辆停车礼让内侧靠山车辆，保障通行安全。

口诀3：辅让主，支让干，车让人

详细解释：辅路、支路车辆汇入主干道，必须停车瞭望礼让；所有场景下，行人路权最高，斑马线、路口遇行人必须停车让行。

五、2026 最新扣分标准

口诀 1：12 分：酒逃 假牌 超速五，高速倒逆 代消分

详细解释：酒驾醉驾、肇事逃逸未犯罪、伪造 / 变造 / 套用证件号牌、超速 50% 以上、高速 / 快速路倒车 / 逆行 / 穿越隔离带、买分卖分替人消分。

口诀 2：9 分：停牌 不符 高速停，超员 疲劳 大客货

详细解释：未悬挂 / 遮挡污损号牌、驾驶准驾不符车辆、高速 / 城市快速路违规停车、**7 座以上客车超员 50%-100%**、大中型客货车 / 危化车疲劳驾驶。

口诀 3：6 分：闯灯 占道 速二五，暂扣开车 不避校

详细解释：闯红灯、高速占用应急车道、**高速超速 20%-50%**、驾驶证暂扣期间驾车、不按规定避让校车。

口诀 4：3 分：接打手机 乱变道，超速少许 不让人

详细解释：行车手持电话、不按车道行驶、违规超车、不礼让行人、**普通道路超速 20%-50%**、故障未开警示灯光 / 未放警示牌。

口诀 5：1 分：乱开灯光 违标线，高速未系安全带

详细解释：不按规定使用灯光、违反禁令 / 禁止标线、高速 / 快速路未系安全带；

普通道路未系安全带、未贴年检保险标、未随车带行驶证：不扣分，仅警告 / 罚款。

六、罚款与处罚规则

口诀1：无证逃逸 伪证件，二百两千 可拘留

详细解释：无证驾驶、驾驶证暂扣期间驾车、轻微肇事逃逸、伪造行驶证/驾驶证，罚款200-2000元，可并处15日以下拘留。

口诀2：小违小错二十百，灯光标识乱停车

详细解释：轻微交通违规，罚款20-200元，包含灯光使用错误、未张贴标识、临时违规停车等行为。

口诀3：吊证四类：酒 速 罪，逾期不处理

详细解释：吊销驾驶证情形：醉驾、超速50%以上、重大交通事故构成犯罪、满分逾期未处理。

口诀4：扣车四无：无牌无证无检无保

详细解释：车辆无号牌、驾驶人无证、车辆未年检、未购买交强险，交警可依法扣留车辆。

七、交通标志与标线（识图必考）

口诀1：黄警红禁蓝指示，绿路白辅助

详细解释：标志颜色万能区分法：

  • 黄色三角：警告标志（注意危险、行人、弯道、施工）

  • 红色圆圈：禁令标志（禁止停车、超车、通行）

  • 蓝色圆形/方形：指示标志（直行、左转、人行通道）

  • 绿色方形：高速指路标志；白色为辅助标识

口诀2：虚线可跨，实线禁压

详细解释：道路标线核心规则：白色、黄色虚线可临时变道、超车、掉头；单双实线、网状线严禁碾压、跨越、停车。

八、事故应急处置规则

口诀1：先人后物，先止后搬

详细解释：事故处置优先级：优先抢救伤员，财物损失次要；伤员出血先止血、包扎，再搬运转移，禁止盲目拖拽。

口诀2：昏迷侧卧，骨折不动

详细解释：昏迷伤员采用侧卧姿势，防止呕吐物堵塞窒息；骨折、关节损伤伤员，禁止随意移动、复位，简单固定后等待救援。

口诀3：车火先断电，燃油不用水

详细解释：车辆起火第一时间切断电源；汽油、燃油起火严禁用水扑救，会导致火势扩散，需使用干粉灭火器、沙土灭火。

九、高速行驶专项规则

口诀1：高速故障：闪灯、摆牌、人撤离

详细解释：高速车辆故障，立刻开启双闪警示灯，车后150米放置警示牌，车上人员全部撤离至高速护栏外侧，禁止在车内、车道停留。

口诀2：高速四禁：倒、逆、占道、急停

详细解释：高速公路严禁倒车、逆行、随意掉头、低速长期占用超车道、占用应急车道行驶/停车，违规直接重罚扣分。

十、驾驶证年限与换证规则

口诀1：6、10、长期

详细解释：驾驶证有效期阶梯规则：初次领证有效期6年；6年内无满分记录，换10年有效期驾照；10年内无满分记录，换终身长期驾照。

口诀2：期满90天，变更30天

详细解释：驾照到期换证，需提前90日内申请；驾驶证住址、联系方式等信息变更，30日内到车管所备案。

口诀3：实习一年，禁独上高速

详细解释：领证后12个月为实习期，车辆需粘贴实习标志；实习期内禁止单独驾驶机动车上高速，需3年以上驾龄老司机陪同。

十一、恶劣天气通用准则

口诀：雨雾冰雪：减速、控距、亮灯、缓行

详细解释：所有恶劣天气统一操作：降低车速、拉大安全跟车距离、开启示廓灯和雾灯，禁止急加速、急刹车、随意变道超车。

十二、判断题万能秒杀口诀

✅ 全对关键词（看到直接选正确）

安全、减速、礼让、观察、缓慢、停车、避让、止血、救人、报警、谨慎、低速

❌ 全错关键词（看到直接选错误）

加速、迅速、紧急制动、立即通过、不用避让、快速穿插、盲目超车、高速占道

💡 特殊秒杀规则

抢救伤员优先、报警处置一律正确；擅自驶离、自行撤离、不报警、不避让一律错误；高速所有违规超车、占用应急车道行为全部错误。
